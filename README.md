# Todo App

A simple Todo App built using HTML, CSS, and JavaScript.

## Features

* Add new tasks
* Edit existing tasks
* Delete individual tasks
* Reset input field
* Clear all tasks

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla)
